# 2D Dungeon

v1 prototype

explore the floors of the 2d dungeon in roguelike fashion 

## Run

Use Go 1.26.2 or newer and a desktop environment with graphics and audio support.

```sh
go run ./cmd
```

Start directly in the developer playground:

```sh
go run ./cmd --testing
```

Build a local executable:

```sh
go build -o 2d-dungeon ./cmd
```
